# CUAC 多语言架构与首发范围

日期：2026-09-21

状态：语言域契约、公开首页、全站搜索以及学校/项目/奖学金/城市目录的发现界面、详细筛选控件和核心详情标签已建立；指南、账户与学生工作区、通知模板和正式法律译文仍按阶段实施。学校管理后台和网站运营管理后台固定为简体中文，不进入公开学生语言发布范围。

当前公开首页、公共导航以及学校/项目/奖学金/城市目录的核心标题、详细筛选、排序、卡片状态、结果上下文、数量、空态、错误、分页、收藏控件和详情页核心标签/状态/操作已提供英语、越南语、泰语、印尼语、马来语和阿拉伯语。阿拉伯语启用 RTL；语言选择使用 URL 参数，可按浏览器语言自动进入，但不会写入 Cookie 或浏览器持久存储。目录跨页及详情页动态链接会保留语言参数。尚未完成审核的官方名称、招生正文、城市来源字段和长篇说明继续明确显示原文，不伪装成已完成翻译。

全站搜索的界面、状态、分页和错误提示已覆盖六种公开语言，并为常用越南语、泰语、印尼语、马来语和阿拉伯语招生词建立受测试的英语规范词映射。学校、项目、奖学金、城市及指南的官方名称和结果摘要仍保留当前已核验的英语/中文目录字段；非英语搜索页会在搜索前明确说明这一边界。

三个核心目录页共用 `catalog-list-i18n.js`，避免每页各自解析语言或持久化状态。动态筛选与排序、卡片 UI 状态、加载/错误状态、结果数量、分页无障碍名称和收藏按钮使用同一词典；新增 DOM 节点会自动应用 UI 翻译，链接也会在当前非英语语言下补充 `lang`，防止进入详情或跨目录后退回英语。目录卡片的官方字段不通过 UI 词典改写。

学校、项目和奖学金详情页共用 `catalog-detail-i18n.js`。来源状态、摘要标签、核心字段、主要操作、加载/错误状态和本地化日期使用同一词典；共享导航及异步生成的详情链接会保留 `lang`。学校名称、项目名称、奖学金名称、招生要求和官方说明保持已核验原文。

## 1. 首发语言

公开学生端的首发目标语言为：

| 代码 | 语言 | 方向 | 用途 |
| --- | --- | --- | --- |
| `en` | English | LTR | 默认语言和未翻译普通内容的明确回退语言 |
| `vi` | Tiếng Việt | LTR | 越南学生端 |
| `th` | ไทย | LTR | 泰国学生端 |
| `id` | Bahasa Indonesia | LTR | 印尼学生端 |
| `ms` | Bahasa Melayu | LTR | 马来语学生端 |
| `ar` | العربية | RTL | 阿拉伯语学生端，必须完成从右到左布局验收 |

`zh-CN` 继续作为正式政策既有版本和中文用户语言，但不代替上述国际学生语言。学校管理后台与网站运营/管理后台在当前产品范围内仅提供简体中文：不显示公开语言选择器，不承担六种学生语言的覆盖率门禁，也不得因后台仅中文而降低公开网站或学生工作区的翻译要求。菲律宾等英语使用场景首发使用英语；新增缅甸语、高棉语、老挝语或他加禄语需要依据真实用户量、客服能力和审核资源单独启用。

语言域按使用者而不是按技术目录划分：公开发现页、登录注册、学生中心、收藏、申请组合、学生通知和学生可见错误均属于学生端，必须进入多语言覆盖；学校员工工作区和网站运营工作区属于后台，默认且仅使用简体中文。一个账号若拥有多个工作区，进入学生工作区后仍适用学生端语言规则，进入学校工作区后切换为后台中文规则。

## 2. 语言选择顺序

普通 UI 按以下顺序解析：显式页面选择、登录账户偏好、浏览器 `Accept-Language`、英语。地区标签会归一化，例如 `vi-VN` 为 `vi`、`ar-SA` 为 `ar`、旧式 `in-ID` 为 `id`。未知语言不会写入账户，也不会被猜测成相近语言。

公开页面只有在对应页面达到完整翻译门槛后才显示该语言选项。不得出现“导航是越南语、正文仍是英语”而没有提示的混合页面。

## 3. 回退边界

- 普通说明内容缺少译文时可以明确标记“以英语显示”，并记录缺失翻译指标。
- 学校、项目和奖学金的官方名称与官方原文必须保留；平台翻译应标记为翻译，不得覆盖来源原文。
- 隐私声明、儿童隐私、服务条款、Cookie、申请披露和需要用户确认的文本不得静默回退。对应语言未审核发布时，确认动作保持阻断。
- 邮件、站内通知和错误信息必须使用同一语言域；不能在一封消息中拼接多种语言模板。

## 4. 实施顺序

1. 统一语言代码、方向、解析、账户读取与覆盖率检测。
2. 抽离公共导航、页脚、通用按钮、错误状态和格式化规则。
3. 完成首页、学校、项目、奖学金、城市、指南和全站搜索。
4. 完成登录、注册、学生中心、收藏、申请组合和学生通知；学校与网站管理后台维持简体中文并做语言域隔离测试。
5. 完成邮件、通知、数据权利和监护同意模板。
6. 独立准备并审核每种语言的法律文件；未批准版本不得发布。
7. 对每个语言执行桌面、移动端、长文本、字体、键盘、读屏和无障碍测试；阿拉伯语另做 RTL、双向文本、数字和表单顺序测试。

## 5. 发布门禁

每个语言必须独立满足：关键流程无缺失键、无未标记英语回退、无截断或控件溢出、日期和数字格式正确、邮件往返通过、搜索有验收词表、法律确认使用同语言已发布版本。某一语言未通过不得影响英语站上线，但该语言不得出现在公开选择器中。

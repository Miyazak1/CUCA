# CUAC 香港上线外部信息补齐清单

日期：2026-09-20

用途：只列仓库无法自行证明、需要项目负责人或供应商提供的事实。不要在本文件、聊天或 Git 中放密码、密钥、验证码或完整控制台截图。

## 第一批：现在即可准备

- [ ] 香港应用服务器：云厂商、账号主体、区域/可用区、资源 ID、出口 IP。
- [ ] PostgreSQL：主库、只读副本、WAL、自动备份、手工快照和灾备的产品及区域。
- [ ] 邮件：准备使用的提供方、发送域、SMTP 区域、退信/投诉日志位置和供应商保存期。
- [ ] 边缘：DNS、CDN、WAF、TLS 证书终止位置、访问日志区域与期限。
- [ ] 监控：错误跟踪、日志、指标、告警和客服/工单产品；是否接收邮箱、IP、用户 ID 或截图。
- [ ] 运维：可登录生产的岗位和常驻地区；是否存在内地、香港以外或外包人员。
- [ ] 备份：滚动期限、跨区复制、手工快照审批、恢复隔离和删除墓碑重放方式。
- [ ] 首批学校：法定名称、联系人、接收字段、用途、保存期、权利渠道和停止合作后的删除方式。

## 第二批：购买/开通服务时提供

- [ ] 每个供应商的合同主体、隐私条款、数据处理协议、分包方清单和安全材料。
- [ ] `cuca.com` 的 `privacy@`、`support@`（可选 `legal@`）已开通、启用 MFA 并完成双向投递。
- [ ] 阿里云 Direct Mail 的真实区域、域名验证、投递/退信验收和最小权限凭据。
- [ ] RDS 的 `verify-full` 证书、私网 ACL、备份恢复和故障切换验收。
- [ ] WAF/共享限流、健康摘流、告警送达和生产密钥轮换证据。

## 第三批：法务/业务决定

- [ ] 运营主体、注册地址、注册地、公开联系方式及是否需要内地代表/机构。
- [ ] 中国内地至香港采用的跨境机制及备案、认证、安全评估或豁免结论。
- [ ] 境外接收方告知和单独同意文案；不满 14 岁由监护人同意的方式。
- [ ] 中英文隐私规则、儿童规则、服务条款、Cookie 说明和招生数据规则批准。
- [ ] 数据保留期限表批准；法律保留例外和独立复核角色确认。
- [ ] 数据泄露、监管联络、个人通知和学校协作流程批准。

## 证据记录方式

每项只在仓库保存脱敏摘要和不可逆证据摘要，例如 `artifact:sha256:<digest>`；完整合同、控制台导出和联系人资料放在受控文档库。证据需注明采集日期、采集人、资源 ID、区域、验证动作和复核人，不得只写“已确认”。
